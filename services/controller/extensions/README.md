# Bundled ARES extensions

These folders ship in the repo. The live WebUI also loads from
`$HOME/.ares/webui/extensions`.

| Id | Source | What it adds |
| --- | --- | --- |
| `astronomy` | already in ARES | Telescope / night-planning tab |
| `ares-worldview` | Desktop WorldView → sibling `ares-worldview` | Globe / tactical intel tab |
| `assistant-avatar` | Hermes WebUI archive | Assistant avatar tab |
| `auto-list` | Hermes WebUI archive | Auto-list composer helper |
| `custom-avatar` | Hermes WebUI archive | Custom avatar |
| `custom-branding` | Hermes WebUI archive | Product branding overlay |
| `desktop-companion` | Hermes WebUI archive | Desktop companion / pets |
| `external-app-tab` | Hermes WebUI archive | Iframe a self-hosted app as a tab |
| `home-scenes` | Desktop `06_Scripts_Shortcuts/home-scenes` | Lighting scene scripts |
| `mcp-tool-shortcuts` | Hermes WebUI archive | Pin MCP tools into the composer |
| `skin-pack` | Hermes WebUI archive | Extra skins |
| `theme-creator` | Hermes WebUI archive | Theme editor tab |
| `typography` | Hermes WebUI archive | Typography controls |

Minecraft stays a sibling install at `~/.ares/webui/extensions/ares-minecraft`.
