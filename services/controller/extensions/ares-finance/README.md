# 💳 ARES Financial Intelligence & Card Optimizer

An offline-first, private financial intelligence extension for ARES and JaegerAI.

## Features

- **Monarch Money Sync**: Pulls account balances, transactions, and categories using `monarchmoneycommunity`.
- **Offline SQLite Store**: Fast, private, local database that powers instant agent turns without hitting external APIs during conversations.
- **Card Multiplier Engine**: Recommends the highest reward multiplier card in your wallet (e.g. 5x gas/groceries, 3x dining/EV, 2x catch-all).
- **ARES Tab HUD**: A sleek dark-mode financial dashboard integrated into ARES WebUI.
- **JaegerAI Tooling**: Allows the assistant to answer questions like *"How much have I spent on groceries this month?"* or *"Which card should I swipe at Costco?"*
